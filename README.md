# Reader Collection

Reader Collection is an app for register and store all data of books you have read, are reading or
want to read. You can store different information about a book, like its name and summary,
the format you are reading it (Physical, Digital or Audiobook), the date when you read it
or the score you want to give it, among others.

You can also add friends and see their libraries, as they can see your library too.

Download it
from [Google Play](https://play.google.com/store/apps/details?id=aragones.sergio.readercollection).

- Navigation Compose
- Coil
- Material3
- Firebase Auth
- Firebase Firestore
- Firebase Crashlytics
- Firebase Remote Config
